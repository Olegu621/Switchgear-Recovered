# Незавершённые эксперименты

Здесь сохранены исходники экспериментов, использованных после основного восстановления. Это не готовый мод и не средство автоматической активации.

- `work/` — собственные сценарии захвата, разбора, изменения байткода, инструменты Ghidra и C-мост для локальной загрузки.
- `lab/` — актуальные smali и манифест приложения-инструментария `com.xlammod.lab`.
- `candidate-overlay/` — изменённые файлы пробного приложения относительно полного `switchgear-recovered/apktool`; остальное берётся из полного архива релиза. Вариант запускает основную игру без подтверждённой работы мода.
- `native/` — дополнительные результаты анализа нативного загрузчика и упрощения переходов.
- `variants/` — точные диагностические варианты байткода из последнего эксперимента. Названия функций раскрывают стек; отдельные изменения нужны для диагностики ошибки, их нельзя считать готовым исправлением.
- `SCRIPT_REVERSE_STATE.md` — рабочая записка с адресами, наблюдениями, ограничениями и возможными следующими шагами.

Сценарии сохраняют локальные пути исходного окружения. Перед использованием настройте пути, подключение ADB и инструменты. Историческая структура рабочей папки: `work/`, `outputs/switchgear-recovered/`, `outputs/switchgear-script-reversed/`; каталоги `recovered/` и `script-reversed/` этого репозитория соответствуют содержимому двух последних путей. Полные файлы для пересборки находятся в архивах релиза.

Ключ подписи тестового APK и его пароль исключены; для своей установки создайте собственный ключ. Не запускайте диагностические сценарии на единственной копии приложения или данных. После последнего эксперимента временные ограничения сети и процесс захвата были удалены.
