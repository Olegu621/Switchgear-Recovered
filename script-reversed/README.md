# Switchgear: извлечённый и разобранный скрипт

Дата: 27 октября 2026. Исходный APK: Switchgear-69.252-v3.2.apk. В приложении отображается Switchgear v12.311.

Восстановлены три модуля, которые исходный загрузчик передаёт модифицированному движку QuickJS. Основной модуль извлечён после загрузки, до чтения байткода движком. Защита таблиц строк расшифрована отдельно. Формат функций и инструкций разобран полностью: парсер потребляет каждый байт, а обратная сериализация всех трёх модулей даёт побайтовое совпадение с выгрузкой.

## Что открыть

- `data/modules/003-reader-ef69062c1059.ir.txt` — читаемый листинг всех функций основного модуля, с именами распознанных операций, переходами и строками. Большие строки сокращены только в листинге.
- `data/modules/003-reader-ef69062c1059.ir.json` — полная структура функций, замыканий, констант и инструкций; подходит для дальнейшего изменения и генерации кода.
- `data/modules/003-reader-ef69062c1059.atoms.json` — все атомы и строки без сокращения после первого слоя расшифровки.
- `data/modules/string-pool-decoded.json` — дополнительно раскрытая таблица из 3 912 строк: интерфейс, переводы и другие константы.
- `data/modules/numeric-pool-decoded.json` — дополнительно раскрытые 798 числовых констант.
- `data/modules/game-data-recovered.json` — восстановленная встроенная таблица игровых данных.
- `reconstructed/constant-pools.cjs` — читаемый JavaScript двух восстановленных декодеров таблиц. Результаты сверены со всеми строками и числами.
- `native/quickjs-vm.c` — декомпиляция нативного исполнителя и дополнительной функции, ранее не прошедших декомпиляцию из-за ограничения времени.
- `data/opcode-metadata.json`, `data/opcode-semantics.json` — структура операндов и связь с нативным исполнителем.
- `evidence/verification-summary.json` — результаты проверки полноты.

## Предел результата

Это полный структурный разбор извлечённых модулей и раскрытие указанных таблиц констант. Это ещё не восстановленный исходный проект JavaScript. Исходные имена локальных переменных, комментарии и структура файлов отсутствуют. Часть имён уже была обфусцирована до компиляции.

В основном листинге смысловые имена присвоены 181 379 из 182 802 инструкций. Остальные 1 423 инструкции представлены как `vm_NNN` с полностью прочитанными операндами; соответствующий нативный код находится в `native/quickjs-vm.c`. Декомпилятор выдаёт предупреждения о типах: этот C-файл — материал для анализа, а не проверенный компилируемый исходник.

Побайтовое совпадение доказывает полноту разбора формата и обратной сборки. Оно не доказывает восстановление всей бизнес-логики в читаемый JavaScript и не заменяет запуск изменённого модуля.

## Уже подготовленное изменение

`data/variants/xlamMOD-brand-only.bin` — отдельно пересобранный основной модуль с заменой видимого названия на xlamMOD: один атом и семь вхождений в таблице интерфейса. Его формат повторно разобран без остатка, все 1 953 функции сохранены. Список изменений — рядом в `.changes.json`.

Этот вариант меняет только название. Активация не удалена, обращения к её серверу ещё не отключены. Загрузка варианта в приложение и работа функций мода не проверены. Это не готовый APK xlamMOD.

## Повторение проверки

Требуются Python и пакет из requirements.txt. Для проверки восстановленных JavaScript-декодеров нужен Node.js.

```text
python -m pip install -r requirements.txt
python tools/decode_quickjs_atoms.py --all
python tools/parse_protected_quickjs.py --all
python tools/verify_quickjs_roundtrip.py --all
python tools/export_quickjs_listing.py
node reconstructed/constant-pools.cjs
```

Декодер выполняет исходную ARM64-функцию чтения строк в Unicorn с сохранёнными таблицами алгоритма. Для расчёта потока используется нулевой буфер той же длины; полученный поток применяется XOR к строке. Повторный слой таблиц основного модуля раскрыт ключом 14947, который подтверждён инструкциями входной функции.

В архив не включены пользовательские настройки активации, ключи подписи APK, данные входа и полные снимки памяти процесса.

## Последняя проверка локальной загрузки

Пробный загрузчик в отдельном тестовом приложении прочитал основной модуль из локального файла при блокировке всей его сети. Чтение байткода движком прошло; исполнение остановилось на ошибке инициализации внутри скрипта. Диагностические имена функций позволили локализовать остановки в f_1940 и затем в проверке объекта f_1919. Работоспособность интерфейса и функций мода в этом режиме пока не подтверждена. Тестовые блокировки сети сняты после проверки.

Дополнительно раскрыта карта внутренних модулей (`data/module-map.json`) и 26 нативных методов интерфейса загрузчика (`data/native-callbacks.json`); их декомпиляция находится в `native/loader-callbacks.c`.
