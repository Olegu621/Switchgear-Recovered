# Switchgear — восстановленные материалы

Публичная копия всех материалов, полученных при восстановлении `Switchgear-69.252-v3.2.apk`: редактируемые smali и Android-ресурсы, Java-декомпиляция, C-подобный псевдокод, извлечённые модули QuickJS и инструменты анализа.

**Это декомпиляция и результаты анализа, а не исходный авторский репозиторий. Рабочий APK xlamMOD без активации пока не получен.**

## Скачать полный комплект

Откройте [релиз recovered-2026-10-29](https://github.com/Olegu621/Switchgear-Recovered/releases/tag/recovered-2026-10-29):

- `Switchgear-recovered-public.zip` — полный проект для пересборки, включая игровые ресурсы, исходные библиотеки, четыре DEX, переносимую Java и инструменты.
- `Switchgear-script-reversed.zip` — извлечённые скриптовые модули, расшифрованные таблицы строк и чисел, листинги, JSON-представление и проверка обратной сборки байткода.
- `Switchgear-research.zip` — исходники экспериментального загрузчика, инструментария и изменения пробного приложения. Это незавершённые эксперименты.
- `SHA256SUMS.txt` — контрольные суммы архивов.

GitHub-кнопка **Code → Download ZIP** скачивает просматриваемую часть репозитория. Для пересборки APK нужен полный архив из релиза: большие игровые ресурсы и инструменты хранятся там.

## Пересборка и проверка

Распакуйте `Switchgear-recovered-public.zip`, откройте PowerShell в `switchgear-recovered` и выполните:

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\rebuild.ps1
```

Получится неподписанный APK. Java-декомпиляция и C-псевдокод предназначены для анализа; они не являются готовым Gradle/C++-проектом. Исходный ключ подписи не восстановлен. Внутренние проверки приложения могут влиять на запуск пересобранного APK.

Для скриптовых инструментов и повторения побайтовой проверки см. [`script-reversed/README.md`](script-reversed/README.md).

Пробный загрузчик прочитал локальный основной модуль при блокировке всей сети тестового приложения. Исполнение остановилось на инициализации. Полный читаемый JavaScript, успешная работа мода и отключение только сервера активации пока не подтверждены. Вариант `xlamMOD-brand-only.bin` меняет название; активация в нём сохранена.

## Состав публикации

Данные активации, приватные настройки приложения, ключи подписи, учётные данные, полные снимки памяти процесса и личный снимок игрового лобби не включены. Старые отчёты могут ссылаться на исключённый снимок лобби. Статические образы распакованной библиотеки и сохранённые исполняемые сегменты — материалы анализа кода.

Исходники экспериментов сохранены с исходными локальными путями. Они требуют настройки окружения и не предназначены для слепого запуска. Публикация материалов не меняет прав на код и ресурсы исходного приложения и сторонних компонентов.
